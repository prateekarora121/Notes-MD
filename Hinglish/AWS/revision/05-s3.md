# S3

---

## 1. Buckets, Access & Hosting

### Buckets & Objects

- Object storage, no filesystem; **11 nines durability**, no capacity to provision.
- **Bucket name globally unique**, 3-63 chars, lowercase/numbers/hyphens/dots. Lives in **one region**; no nesting.
- **Key = full path** (flat, no real dirs; console renders prefixes). Max object **5 TB**; **single PUT ≤5 GB** (multipart above, >100 MB recommended). Up to 10 tags.
- ❗ **Strong read-after-write consistency** for PUT/overwrite/DELETE + consistent LIST (since Dec 2020). "Eventually consistent for overwrites" = outdated.
- `aws s3` (cp/sync/mv) vs `aws s3api` (raw). `sync --delete` removes remote extras.

### Bucket Policies & Access Control

| Mechanism | Attaches | Use |
|---|---|---|
| IAM policy | user/role | own workloads |
| Bucket policy | bucket | cross-account, enforce conditions (Principal needed) |
| ACLs (legacy) | bucket/object | ❌ disable via "Bucket owner enforced" |
| Access Points | named endpoint | many-team scale |

Two guardrails to memorise (both Deny):
```json
{"Sid":"DenyUnEncryptedUploads","Effect":"Deny","Principal":"*","Action":"s3:PutObject",
 "Resource":"arn:aws:s3:::my-bucket/*",
 "Condition":{"StringNotEquals":{"s3:x-amz-server-side-encryption":"aws:kms"}}}
{"Sid":"DenyInsecureTransport","Effect":"Deny","Principal":"*","Action":"s3:*",
 "Resource":["arn:aws:s3:::my-bucket","arn:aws:s3:::my-bucket/*"],
 "Condition":{"Bool":{"aws:SecureTransport":"false"}}}
```
- **Block Public Access (BPA):** 4 toggles, account + bucket level, **default on** (2023). Account-level **overrides** bucket. "No public bucket ever?" → account BPA + SCP + Access Analyzer.

### Static Website Hosting

Index + error document; needs public-read bucket policy + BPA off. ❗ **Website endpoint = HTTP only** → real use: **CloudFront + OAC**, private bucket. REST endpoint (HTTPS/IAM) vs website endpoint (index docs, HTTP, public).

### Object Lock & Access Points

- **Object Lock (WORM):** needs versioning + enable at bucket creation. **Governance** (bypass with permission) vs **Compliance** (nobody, not even root). **Legal Hold** = on/off, no expiry. **Glacier Vault Lock** = SEC 17a-4. Compliance = ransomware/insider answer.
- **Access Points:** named endpoints, own policy/DNS, VPC-restrict; **Multi-Region Access Points**. **Object Lambda Access Points** = transform on GET (redact PII, resize) without second copy.

**DR — S3:** risk = objects + config. Backup = versioning (undelete), MFA Delete, **Object Lock** (ransomware), CRR/SRR, Batch Replication, Glacier lifecycle. Accidental delete → remove delete marker; mass → Batch Operations; regional → repoint to replica; archived → `restore-object` (Deep Archive ~12h). ⚠️ CRR only replicates objects created **after** enable; deletes not replicated by default; versioning alone doesn't stop mass-delete (need Object Lock/MFA Delete).

## 2. Storage Classes, Lifecycle & Versioning

### Versioning & Replication

- Versioning: bucket-level, only suspend (never off); DELETE = **delete marker** (undelete by removing marker; permanent needs version ID); prerequisite for replication + MFA Delete. **Cost:** pay per version → pair with lifecycle expiring noncurrent versions.
- **CRR (cross-region)** = DR/latency/compliance; **SRR (same-region)** = log aggregation/test seeding. Rules: versioning both sides + IAM role; async, **not retroactive** (backfill = S3 Batch Replication); delete markers optional, permanent deletes never replicate; **no chaining**; RTC = 15-min SLA; Multi-Region Access Points = active-active.

### Storage Classes & Lifecycle

| Class | Use | Min duration | Retrieval |
|---|---|---|---|
| Standard | frequent | none | immediate |
| Intelligent-Tiering | unknown | none | immediate (auto) |
| Standard-IA | infrequent | 30d | immediate |
| One Zone-IA | infrequent recreatable | 30d | immediate |
| Glacier Instant | archive ms | 90d | immediate |
| Glacier Flexible | archive | 90d | min-hours |
| Glacier Deep Archive | compliance | 180d | ~12h |

```json
{"Rules":[{"ID":"...","Status":"Enabled","Filter":{"Prefix":"logs/"},
  "Transitions":[{"Days":30,"StorageClass":"STANDARD_IA"},{"Days":90,"StorageClass":"GLACIER"}],
  "Expiration":{"Days":365}}]}
```
- Gotchas: IA retrieval fees; **min-duration billing** even if early delete/transition; Intelligent-Tiering monitoring fee; versioning+lifecycle interact (noncurrent needs own rule).
- **Real patterns:** logs → tier down + expire; backups → Deep Archive day 1; unpredictable → Intelligent-Tiering; compliance → no expiration; scratch → expire 1-7d no transition. Check min-duration vs real lifetime before adding transition.
- Terraform: `aws_s3_bucket_lifecycle_configuration` with `noncurrent_version_expiration` for versioned buckets.

## 3. Performance, Cost & Operations

### Performance, Analytics, Batch, Requester Pays

- **3,500 PUT / 5,500 GET per second per prefix**, unlimited prefixes → spread keys.
- Multipart (>5GB required, abort-incomplete lifecycle rule), Transfer Acceleration (edge upload), byte-range fetch, S3 Select (server-side SQL on one object).
- Analytics: Storage Lens (org dashboards), Storage Class Analysis, S3 Inventory (report + Batch manifest), CloudWatch, event notifications (Lambda/SQS/SNS/EventBridge).
- **Batch Operations:** billions of objects from manifest (copy/tag/ACL/Glacier restore/Object Lock/per-object Lambda). "40M unencrypted objects — fix?" → Inventory + Batch, not a loop.
- **Requester Pays:** requester pays request+egress, owner pays storage; must be authenticated + send `x-amz-request-payer: requester`.

## 4. Security & Compliance

### S3 Security — 4 Encryption Types

| Type | Key holder | Audit | When |
|---|---|---|---|
| SSE-S3 | AWS (AES-256) | none | Default (auto since 2023), free |
| SSE-KMS | Your KMS key | ✅ CloudTrail | Auditability/rotation; needs `s3:GetObject` **+ `kms:Decrypt`** |
| DSSE-KMS | KMS, dual-layer | ✅ | strict mandates |
| SSE-C | You (key in header) | limited | sole key custody, HTTPS mandatory |
| Client-side | You (before AWS) | N/A | zero-trust |

- ❗ **SSE-KMS gotcha:** each GET/PUT = KMS call (per-region quota → `ThrottlingException`). Fix = **S3 Bucket Keys** (99% fewer KMS calls).
- In-transit = HTTPS, **enforced** via `aws:SecureTransport` deny.

### CORS, MFA Delete, Access Logs, Pre-signed URLs

- **CORS:** browser cross-origin — configure on bucket. `AllowedOrigins` exact (scheme+host+port); `ExposeHeaders` for `ETag`; presigned uploads need PUT CORS rule.
- **MFA Delete:** MFA to permanently delete version / suspend versioning. Versioning first; only **root** via **CLI/API**. Most use Object Lock instead.
- **Access Logs:** ⚠️ **never target the logged bucket** (infinite loop). Best-effort/delayed. **Access logs vs CloudTrail data events:** for "who deleted?" / security → CloudTrail data events (real-time, IAM identity).
- **Pre-signed URLs:** carries generator's permissions. 7 days (IAM user key) / 1h (CLI). ❗ Generated with **temp role creds** (Lambda/ECS/EC2) → dies when creds expire (~1h) regardless of requested expiry. Use for authenticated download + direct browser upload (don't stream through compute).
